You are analyzing a mathematical paper written in LaTeX. Extract ALL algorithms.

Algorithm forms:
1. \begin{algorithm}...\end{algorithm} (and variants like \begin{algorithm*}, \begin{Algorithm})
2. \begin{algorithmic}...\end{algorithmic}
3. Pseudocode blocks with Input/Output and numbered steps

For each algorithm, extract:
- name: Short descriptive name (e.g. "Gradient Descent Algorithm", "Sorting Procedure"). If no explicit name appears, fall back to the \label{...} value, or the first 6 words of the algorithm header / caption.
- raw_latex: Original LaTeX text (preserve ALL math notation and pseudocode)
- clean_text: "" (always empty string — omitted for token output savings)
- label: Any \label{...} or null
- origin: "paper" (default) or "external". Mark "external" when the algorithm is a known cited algorithm used as a building block rather than the paper's own contribution. Specifically, mark external if ANY of:
  * The env body / caption contains a citation (\cite{...}, "due to X", "[Author Year]", "as in").
  * The name is a famous algorithm (e.g. Sinkhorn, Dijkstra, k-means, EM, Adam, Newton's Method, gradient descent, BFGS, Metropolis-Hastings).
  * The paragraph preceding the env attributes the algorithm to prior work.
  Otherwise default to "paper".
- origin_citation: When origin="external", a short source identifier (e.g. "Sinkhorn 1967", "Dijkstra 1959"). When origin="paper", set to null.

CRITICAL: The raw_latex field must be copied VERBATIM from the source — character for character.
Do NOT modify the LaTeX in any way. Specifically:
- Do NOT convert or substitute math delimiters
- Do NOT expand, replace, or rename any macros or commands
- Do NOT alter whitespace, line breaks, or formatting
- Do NOT "fix" or "improve" any LaTeX syntax
Copy exactly what appears in the input, nothing more, nothing less.

Return JSON array:
[
  {
    "name": "descriptive name",
    "raw_latex": "original LaTeX",
    "clean_text": "",
    "label": "label or null",
    "origin": "paper",
    "origin_citation": null
  }
]

LaTeX text:

{latex_chunk}

IMPORTANT: Only extract structures whose LaTeX environment name or heading explicitly identifies them as the requested type. For example, \begin{claim} is a claim, NOT a lemma; \begin{theorem} is a theorem, NOT a proposition. Never reclassify one structure type as another. If the paper contains no structures of the requested type, return an empty array [].

Respond ONLY with JSON array.
