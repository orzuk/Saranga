# Per-type prompt: extracts CONJECTURE nodes only. Schema lock 2026-05-21
# (added origin / origin_citation fields).
# Note: a conjecture has a stated answer the author believes true. Unsolved
# *questions* without a stated answer are open_problem (see open_problem_prompt.txt).

You are analyzing a mathematical paper written in LaTeX. Extract ALL mathematical conjectures.

Conjecture forms:
1. \begin{conjecture}...\end{conjecture} (and variants like \begin{conj}, \begin{Conjecture})
2. "Conjecture 2.1. ..."
3. "We conjecture that ...", "It is conjectured that ..."

For each conjecture, extract:
- name: Short descriptive name (e.g. "Main Conjecture", "Density Conjecture"). If no explicit name appears, fall back to the \label{...} value, or the first 6 words of the statement.
- raw_latex: Original LaTeX text (preserve ALL math notation)
- clean_text: "" (always empty string — omitted for token output savings)
- label: Any \label{...} or null
- assumptions: The hypotheses/conditions
- statement: The conjectured claim
- origin: "paper" (default) or "external". Mark "external" when the conjecture is a restatement of a prior result rather than the paper's own contribution. Specifically, mark external if ANY of:
  * The env body contains a citation (\cite{...}, \cite[...], "due to X", "[Author Year]", "shown in", "proved in", "following Y").
  * The optional name argument identifies a famous named conjecture (e.g. \begin{conjecture}[Hodge], [BSD], [Birch--Swinnerton-Dyer], [Mukai], [Tate], [Standard], [Iitaka], [Vojta], [Lang], [Beilinson], [Bloch--Kato]).
  * The paragraph immediately preceding the env attributes the conjecture to prior work.
  Otherwise default to "paper".
- origin_citation: When origin="external", a short source identifier (e.g. "Hodge 1950", "BSD 1965"). When origin="paper", set to null.

CRITICAL: The raw_latex field must be copied VERBATIM from the source — character for character.
Do NOT modify the LaTeX in any way. Specifically:
- Do NOT convert or substitute math delimiters
- Do NOT expand, replace, or rename any macros or commands
- Do NOT alter whitespace, line breaks, or formatting
- Do NOT "fix" or "improve" any LaTeX syntax
Copy exactly what appears in the input, nothing more, nothing less.

Return JSON array:
[
  {
    "name": "descriptive name",
    "raw_latex": "original LaTeX",
    "clean_text": "",
    "label": "label or null",
    "assumptions": "hypotheses text",
    "statement": "conjectured claim text",
    "origin": "paper",
    "origin_citation": null
  }
]

LaTeX text:

{latex_chunk}

IMPORTANT: Only extract structures whose LaTeX environment name or heading explicitly identifies them as the requested type. For example, \begin{claim} is a claim, NOT a lemma; \begin{theorem} is a theorem, NOT a proposition. Never reclassify one structure type as another. If the paper contains no structures of the requested type, return an empty array [].

Respond ONLY with JSON array.
