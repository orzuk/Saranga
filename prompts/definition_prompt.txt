You are analyzing a mathematical paper written in LaTeX. Extract ALL mathematical definitions.

Definition forms:
1. \begin{definition}...\end{definition}
2. "Definition 2.1. ..."
3. "We define X as/to be ...", "X is defined as ...", "Let X be ..."
4. Implicit definitions with new notation

For each definition, extract:
- name: Short descriptive name. If no explicit name appears, fall back to the \label{...} value, or the first 6 words of the definition body.
- raw_latex: Original LaTeX text (preserve ALL math notation)
- clean_text: "" (always empty string — omitted for token output savings)
- label: Any \label{...} or null
- origin: "paper" (default) or "external". Most definitions are paper-original. Mark "external" only when the paper explicitly recalls a definition from a cited source — e.g. "we recall the Sinkhorn divergence (Sinkhorn 1967)", "following Cover & Thomas, define ...", or the env body contains \cite{...} attributing the definition to prior work.
- origin_citation: When origin="external", a short source identifier (e.g. "Sinkhorn 1967", "Cover & Thomas"). When origin="paper", set to null.

CRITICAL: The raw_latex field must be copied VERBATIM from the source — character for character.
Do NOT modify the LaTeX in any way. Specifically:
- Do NOT convert or substitute math delimiters
- Do NOT expand, replace, or rename any macros or commands
- Do NOT alter whitespace, line breaks, or formatting
- Do NOT "fix" or "improve" any LaTeX syntax
Copy exactly what appears in the input, nothing more, nothing less.

Return JSON array:
[
  {
    "name": "descriptive name",
    "raw_latex": "original LaTeX",
    "clean_text": "",
    "label": "label or null",
    "origin": "paper",
    "origin_citation": null
  }
]

LaTeX text:

{latex_chunk}

IMPORTANT: Only extract structures whose LaTeX environment name or heading explicitly identifies them as the requested type. For example, \begin{claim} is a claim, NOT a lemma; \begin{theorem} is a theorem, NOT a proposition. Never reclassify one structure type as another. If the paper contains no structures of the requested type, return an empty array [].

Respond ONLY with JSON array.
