# Per-type prompt: extracts PROOF nodes only. Schema lock 2026-05-21
# (added origin / origin_citation fields).
# Level-2 proof_step nodes are emitted by a SEPARATE pass when caller
# requests `with_proof_steps` granularity — not by this prompt.

You are analyzing a mathematical paper written in LaTeX. Extract ALL mathematical proofs.

Proof forms:
1. \begin{proof}...\end{proof} (and variants like \begin{Proof})
2. \begin{proof}[Proof of Theorem~\ref{...}]...\end{proof}
3. "Proof. ..." followed by a QED symbol or \qedhere

For each proof, extract:
- name: What it proves (e.g. "Proof of Theorem 2.1", "Proof of Main Lemma")
- raw_latex: Original LaTeX text (preserve ALL math notation)
- clean_text: "" (always empty string — omitted for token output savings)
- label: Any \label{...} or null
- origin: "paper" (default) or "external". Most proofs are paper-original. Mark "external" only when the paper explicitly reproduces or sketches a proof from prior work — e.g. "We reproduce the proof from [Smith 1990]", "The argument below is due to Tao (2008)", or the env body opens with \cite{...} attributing the proof.
- origin_citation: When origin="external", a short source identifier (e.g. "Smith 1990"). When origin="paper", set to null.

CRITICAL: The raw_latex field must be copied VERBATIM from the source — character for character.
Do NOT modify the LaTeX in any way. Specifically:
- Do NOT convert or substitute math delimiters
- Do NOT expand, replace, or rename any macros or commands
- Do NOT alter whitespace, line breaks, or formatting
- Do NOT "fix" or "improve" any LaTeX syntax
Copy exactly what appears in the input, nothing more, nothing less.

Return JSON array:
[
  {
    "name": "what it proves",
    "raw_latex": "original LaTeX",
    "clean_text": "",
    "label": "label or null",
    "origin": "paper",
    "origin_citation": null
  }
]

LaTeX text:

{latex_chunk}

IMPORTANT: Only extract structures whose LaTeX environment name or heading explicitly identifies them as the requested type. For example, \begin{claim} is a claim, NOT a lemma; \begin{theorem} is a theorem, NOT a proposition. Never reclassify one structure type as another. If the paper contains no structures of the requested type, return an empty array [].

Respond ONLY with JSON array.
