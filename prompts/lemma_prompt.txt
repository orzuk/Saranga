You are analyzing a mathematical paper written in LaTeX. Extract ALL mathematical lemmas.

Lemma forms:
1. \begin{lemma}...\end{lemma} (and variants like \begin{lem}, \begin{Lemma})
2. "Lemma 2.1. ..."
3. Formally stated lemmas with assumptions and conclusions

For each lemma, extract:
- name: Short descriptive name (e.g. "Key Lemma", "Approximation Lemma"). If no explicit name appears, fall back to the \label{...} value, or the first 6 words of the statement.
- raw_latex: Original LaTeX text (preserve ALL math notation)
- clean_text: "" (always empty string — omitted for token output savings)
- label: Any \label{...} or null
- assumptions: The hypotheses/conditions (e.g. "Let X be a compact space", "Suppose f is continuous")
- statement: The main claim/conclusion (e.g. "Then f has a fixed point")
- origin: "paper" (default) or "external". Mark "external" when the lemma is a restatement of a prior result rather than the paper's own contribution. Specifically, mark external if ANY of:
  * The env body contains a citation (\cite{...}, \cite[...], "due to X", "[Author Year]", "shown in", "proved in", "established by").
  * The optional name argument identifies a famous named lemma (e.g. \begin{lemma}[Zorn], [Schwarz], [Nakayama], [Yoneda], [Burnside], [Frobenius], [Fatou], [Itô]).
  * The paragraph immediately preceding the env attributes the lemma to prior work.
  Otherwise default to "paper".
- origin_citation: When origin="external", a short source identifier (e.g. "Zorn 1935", "Nakayama"). When origin="paper", set to null.

CRITICAL: The raw_latex field must be copied VERBATIM from the source — character for character.
Do NOT modify the LaTeX in any way. Specifically:
- Do NOT convert or substitute math delimiters
- Do NOT expand, replace, or rename any macros or commands
- Do NOT alter whitespace, line breaks, or formatting
- Do NOT "fix" or "improve" any LaTeX syntax
Copy exactly what appears in the input, nothing more, nothing less.

Return JSON array:
[
  {
    "name": "descriptive name",
    "raw_latex": "original LaTeX",
    "clean_text": "",
    "label": "label or null",
    "assumptions": "hypotheses text",
    "statement": "conclusion text",
    "origin": "paper",
    "origin_citation": null
  }
]

LaTeX text:

{latex_chunk}

IMPORTANT: Only extract structures whose LaTeX environment name or heading explicitly identifies them as the requested type. For example, \begin{claim} is a claim, NOT a lemma; \begin{theorem} is a theorem, NOT a proposition. Never reclassify one structure type as another. If the paper contains no structures of the requested type, return an empty array [].

Respond ONLY with JSON array.
