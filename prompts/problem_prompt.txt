# (added origin / origin_citation fields).

# IMPORTANT: This prompt extracts the `problem` type ONLY. Open mathematical
# questions ("Open Problem: ...") are now a SEPARATE type, `open_problem`,
# extracted by `open_problem_prompt.txt`. Do NOT extract `\begin{openproblem}`
# blocks or "Open Problem:" headings here — leave those for the open_problem
# extractor.

You are analyzing a mathematical paper written in LaTeX. Extract ALL mathematical problems
that are NAMED OR FORMULATED FORMAL problems being studied (NOT open questions).

A `problem` is a named or formulated formal mathematical problem the paper studies:
- optimization formulations ("argmin f(x) s.t. Ax<=b"),
- decision problems ("3-SAT"),
- named problems with attached algorithms / complexity / hardness
  ("the knapsack problem", "the isoperimetric problem").

A `problem` is NOT:
- an unsolved mathematical *question* with no known solution
  ("Are there infinitely many odd perfect numbers?") — that is `open_problem`,
  extracted by a separate prompt.
- a pedagogical exercise for the reader — that is `exercise`.

Problem forms (extract these):
1. \begin{problem}...\end{problem} (and variants like \begin{Problem})
   — when the body is a formal/named/studied problem.
2. "Problem 2.1. ..." — numbered formal problems.
3. Optimization / decision-problem formulations explicitly designated as
   "the problem" or "problem (P)" in nearby prose.

Do NOT extract here (leave for `open_problem_prompt.txt`):
- "\begin{openproblem}", "Open Problem:", "Open Question:" headings.

For each problem, extract:
- name: Short descriptive name (e.g. "Main Problem", "Optimization Problem"). If no explicit name appears, fall back to the \label{...} value, or the first 6 words of the statement.
- raw_latex: Original LaTeX text (preserve ALL math notation)
- clean_text: "" (always empty string — omitted for token output savings)
- label: Any \label{...} or null
- assumptions: The given conditions or setup
- statement: The problem statement / what needs to be shown or found
- origin: "paper" (default) or "external". Mark "external" when the problem is a famous prior problem the paper invokes rather than defining its own. Specifically, mark external if ANY of:
  * The env body contains a citation (\cite{...}, "due to X", "[Author Year]", "introduced by", "as defined in").
  * The optional name argument identifies a famous named problem (e.g. \begin{problem}[Travelling Salesman], [Knapsack], [3-SAT], [Subset Sum], [Hamiltonian Path], [Halting]).
  * The paragraph preceding the env attributes the problem to prior work.
  Otherwise default to "paper".
- origin_citation: When origin="external", a short source identifier (e.g. "Knapsack", "3-SAT (Cook 1971)"). When origin="paper", set to null.

CRITICAL: The raw_latex field must be copied VERBATIM from the source — character for character.
Do NOT modify the LaTeX in any way. Specifically:
- Do NOT convert or substitute math delimiters
- Do NOT expand, replace, or rename any macros or commands
- Do NOT alter whitespace, line breaks, or formatting
- Do NOT "fix" or "improve" any LaTeX syntax
Copy exactly what appears in the input, nothing more, nothing less.

Return JSON array:
[
  {
    "name": "descriptive name",
    "raw_latex": "original LaTeX",
    "clean_text": "",
    "label": "label or null",
    "assumptions": "given conditions",
    "statement": "problem statement",
    "origin": "paper",
    "origin_citation": null
  }
]

LaTeX text:

{latex_chunk}

IMPORTANT: Only extract structures whose LaTeX environment name or heading explicitly identifies them as the requested type. For example, \begin{claim} is a claim, NOT a lemma; \begin{theorem} is a theorem, NOT a proposition. Never reclassify one structure type as another. If the paper contains no structures of the requested type, return an empty array [].

Respond ONLY with JSON array.
