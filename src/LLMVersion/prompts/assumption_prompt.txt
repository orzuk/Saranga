# An `assumption` is a \begin{assumption} block declaring standing
# assumptions for a section, theorem cluster, or paper. Common in
# stats / optimization papers ("(A1) f is convex; (A2) X is bounded").
# Distinct from the per-theorem `assumptions` field inside theorem-like nodes.

You are analyzing a mathematical paper written in LaTeX. Extract ALL ASSUMPTION BLOCKS
-- standing assumptions that apply to a section, theorem cluster, or the entire paper.

An `assumption` is:
- A \begin{assumption} or \begin{assumptions} environment declaring
  conditions that hold throughout a section or paper.
- Numbered assumption blocks like "(A1)", "(H1)", "(H2)", "Assumption 1".
- Standing hypotheses explicitly labeled as assumptions that multiple
  results rely on.

An `assumption` is NOT:
- The `assumptions` field inside a theorem/lemma/proposition (those are
  per-theorem hypotheses, not standalone blocks).
- A definition (which introduces a named concept).
- A remark or observation.

For each assumption block, extract:
- name: Short descriptive name (e.g. "Standing Assumptions", "Assumption (A1)")
- raw_latex: Original LaTeX text (preserve ALL math notation)
- clean_text: "" (always empty string -- omitted for token output savings)
- label: Any \label{...} or null
- statement: The assumption statement itself

CRITICAL: The raw_latex field must be copied VERBATIM from the source --
character for character. Do NOT modify the LaTeX in any way. Specifically:
- Do NOT convert or substitute math delimiters
- Do NOT expand, replace, or rename any macros or commands
- Do NOT alter whitespace, line breaks, or formatting
- Do NOT "fix" or "improve" any LaTeX syntax
Copy exactly what appears in the input, nothing more, nothing less.

Return JSON array:
[
  {
    "name": "descriptive name",
    "raw_latex": "original LaTeX",
    "clean_text": "",
    "label": "label or null",
    "statement": "the assumption statement"
  }
]

LaTeX text:

{latex_chunk}

IMPORTANT: Only extract standing assumption blocks as defined above. Do NOT
extract per-theorem hypotheses or conditions within theorem statements.
If the paper contains no assumption blocks, return an empty array [].

Respond ONLY with JSON array.
