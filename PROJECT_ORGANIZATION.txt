================================================================================
AUTHOMATHICS - PROJECT ORGANIZATION
================================================================================

PURPOSE
  Parse arXiv papers, extract math objects (theorems, definitions, proofs,
  equations, algorithms, tables), build knowledge graphs of relationships,
  and optionally ground concepts to Wikidata/ProofWiki.

================================================================================
CLASSES (src/math_classes.py)
================================================================================

MathObject                      Base class for all math objects
  |-- id, kind, index, label, name, raw_latex, clean_text, paper_id, spans
  |
  +-- Equation                  Mathematical equation/formula
  |     env_name, display_type (env/dollar/bracket), parent_id
  |
  +-- TheoremLike               Theorem, Lemma, Proposition, Corollary, Claim
  |     env_name, assumptions, statement, assumption_spans, conclusion_spans
  |     |
  |     +-- Problem             Optimization/existence problems
  |     |     problem_type, constraints, objective, complexity
  |     |
  |     +-- Conjecture          Mathematical conjectures
  |
  +-- Definition                Concept definitions
  |     env_name, definiendum, genus, differentia, equivalences, notation_introduced
  |
  +-- Proof                     Proofs
  |     parent_id, strategy_tags, steps, assumptions, conclusions
  |
  +-- Algorithm                 Algorithmic procedures
  |     env_name, steps, structured_steps, input_params, output_params
  |
  +-- TableObject               Data tables
  |     env_name, caption, cells (2D list)
  |
  +-- Concept                   External (Wikidata) concept entry
        external_ids, aliases, description, registry_source

Span                            Semantic text chunk (role: assumption/conclusion/etc.)
Relation                        Directed edge (source_id, target_id, relation_type, category)
PaperGraph                      Container: objects dict + relations list + helper methods
AlgoParam                       Algorithm parameter (name, description, type)
AlgoStep                        Single algorithm step (number, instruction, substeps)


================================================================================
RELATION TYPES
================================================================================

Type              Category      Meaning
-----------       ----------    -----------------------------------------
uses              logical       A uses B (proof uses lemma, etc.)
depends_on        logical       A depends on B as prerequisite
follows_from      logical       A follows from B (B => A)
has_part          structural    A contains B (theorem has_part proof)
generalizes       conceptual    A generalizes B
related_to        conceptual    Weak conceptual connection (symmetric)
equivalent_to     conceptual    Conceptual equivalence (symmetric)
mentions_concept  conceptual    Object mentions a registry concept
grounded_to       conceptual    Disambiguated concept link

--- src/config.py ---

--- src/math_classes.py ---
  CLASS MathObject:
    to_dict()                   Serialize to dict
    from_dict(d) [classmethod]  Deserialize from dict (dispatches to subclass)
  CLASS PaperGraph:
    add_object(obj)             Register a MathObject
    add_relation(src, tgt, ...) Add an edge
    add_uses(user, used, ...)   Shortcut: "uses" relation
    add_depends_on(thm, pre,..) Shortcut: "depends_on" relation
    add_follows_from(cons, pre) Shortcut: "follows_from" relation
    add_has_part(whole, part)   Shortcut: "has_part" relation
    add_generalizes(gen, spec)  Shortcut: "generalizes" relation
    outgoing(obj_id, rtype)     Get outgoing edges from node
    incoming(obj_id, rtype)     Get incoming edges to node
    to_dict()                   Serialize entire graph
    from_dict(d) [classmethod]  Deserialize entire graph

--- src/math_paper_parser.py ---
  CLASS PaperParser:
    parse_file(path)                     MAIN ENTRY: .tex -> PaperGraph
    _expand_inputs(text, base, d, max)   Recursively expand \input{} / \include{}
    _expand_macros(text)                 Expand \newcommand definitions
    _normalize_simple_ref_macros(text)   Normalize ref wrapper macros
    _strip_comments(text)                Remove LaTeX % comments
    _parse_newtheorem(text)              Parse \newtheorem -> env_kind_map
    _extract_theorem_like(text)          -> List[TheoremLike]
    _extract_definitions_manual(text)    -> List[Definition]
      (A) environment-based via _extract_envs
      (B) textual "Definition N.N." patterns
      (C) inline "Let X be", "define X as" patterns
    _extract_definitions_llm(text, ...)  -> List[Definition] (LLM-based)
    _extract_proofs(text)                -> List[Proof]
    _extract_algorithms(text)            -> List[Algorithm]
    _extract_tables(text)                -> List[TableObject]
    _extract_equations(full, containers) -> List[Equation]
    _extract_equations_from_body(body,p) -> List[Equation] (within a container)
    _link_proofs_to_theorems(graph)      Match proofs to parent theorems
    _build_relations(graph)              Build all edges (has_part, uses, ...)
    _clean_latex_to_text(latex)          LaTeX -> plain text (best effort)
    _extract_label_and_name(body)        Get \label{...} from env body
    _extract_envs(text, env_names)       Generic \begin{E}...\end{E} extractor
    _split_assumptions_statement(text)   Split theorem into assume + state
    _extract_assumptions_conclusions_from_statement(text) Fine-grained split
    _normalize_inline_text(text, max)    Clean up inline text (max 80 chars)
